The maker.

Cobratate was written during a hackathon at the Indian Institute of Technology Jammu, in the course of an internship there. The phrases came first. The evaluator was fitted behind them the same night.

What the language already writes.

These are not proposals. Each file is in the repository and was run. The checked results are in the program catalogue.

Ordinary programs

The first garage

  • Hello — print
  • Grind — a compounding loop
  • FizzBuzz — COBRA, TATE, COBRATATE

  • Garage — lists and indexing
Numerical work

Small software

  • Primes below 50
  • Euclid — gcd 42, lcm 252
  • Fibonacci by recursion
  • Pascal's triangle
  • Collatz hailstones
  • Bases — 42 is 101010
One phrase

One meaning

What color is your Bugatti prints. Grind while loops. Hustle defines a function. Cash out returns. A list is a garage. Put returns a new one.

examples/dsa

Data structures

  • Bubble sort — [5, 1, 4, 2, 8, 0] becomes sorted
  • Linear scan and binary search — 9 at index 4
  • Stack — push, top, pop
  • Two-sum — indices [0, 1]
  • Breadth-first search — visits [0, 1, 2, 3]
examples/ml

Machine learning

  • Linear regression — weight about 1.99 on y = 2x
  • Perceptron — AND classifies as 0 0 0 1
  • One-nearest neighbour — two query classes
  • Min-max scaling — [10, 20, 30] to [0, 0.5, 1]

Universities, colleges, schools

Put it on the syllabus.

The MIT License already permits a class to copy the interpreter and the manual. No separate permission is required. Use it as a laboratory, not as a replacement for a production language. The six-week map runs from the greeting through lists, sorting, search, a graph, and the learning models above.
