# Glossary

beta
: The false boolean, written `BETA`. Also the register of a diagnostic: beta behavior is a failed program, not a moral category.

bugatti
: The assignment keyword. `BUGATTI name EQUALS expression` binds a name. The word is the print statement's joke, not a type.

cash out
: Return from the current hustle.

cobra
: Half of the language's name, from the public nickname Cobra Tate. In `examples/intro/fizz.cbt`, the word printed for a multiple of 3.

garage
: A list value, written `[1, 2, 3]`. Also the metaphor in the unbound-name diagnostic.

grind
: A while-loop, opened by `GRIND WHILE` and closed by `STOP GRINDING`.

hustle
: A function, opened by `HUSTLE` and closed by `DONE HUSTLING`.

matrix
: The program banners, the input expression, and the comment marker `MATRIX:`. In the persona, a name for ordinary life. In the language, only those three roles.

period
: The closer of an `IF`. Not a statement separator. Newlines separate statements.

put
: `CALL put (garage, index, value)` returns a new garage with one index replaced. It does not modify the garage that was passed in.

sigma
: The true boolean, written `SIGMA`. Also the property tested by conditions: non-zero, non-empty, or `SIGMA`.

split
: Floor division, written `SPLIT BY`.

top G
: The read-eval-print prompt, `topg>`. Not a value in the language.
