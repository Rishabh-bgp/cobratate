# Cobratate documentation

Version 1.2. This set is the language manual. It is organised in the same way as the Python documentation: a tutorial for a first reading, a reference for the rules, a library page for the built-in hustles, a program catalogue, and a glossary. The interpreter in `cobratate.py` is the normative implementation.

Cobratate is an esoteric programming language. The vocabulary is borrowed from the public persona of Andrew Tate. The evaluation rules are those of a small imperative language. The project is not affiliated with, endorsed by, or authorised by Andrew Tate or any person or company associated with him.
