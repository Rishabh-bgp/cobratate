# Cobratate documentation

Version 1.2. This is the language manual. It is organised as a tutorial, a reference, a library page, a program catalogue, an error list, and a glossary. The interpreter in `cobratate.py` is the normative implementation. When a page and the interpreter disagree, the interpreter is the specification and the page should be corrected.

Cobratate is an esoteric programming language. The vocabulary is borrowed from the public persona of Andrew Tate. The evaluation rules are those of a small imperative language. The project is not affiliated with, endorsed by, or authorised by Andrew Tate or any person or company associated with him.

The public site is [rishabh-bgp.github.io/cobratate](https://rishabh-bgp.github.io/cobratate/). The project front page is the [README](../README.md).
