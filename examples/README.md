# Examples

The catalogue, with checked results, is [docs/programs.md](../docs/programs.md).

| Directory | Contents |
| --- | --- |
| [intro/](intro) | Print, loops, functions, garages |
| [numbers/](numbers) | Primes, Euclid, Collatz, Fibonacci, binomial coefficients, bases |
| [dsa/](dsa) | Sort, search, stack, two-sum, breadth-first search |
| [ml/](ml) | Linear regression, a perceptron, nearest neighbour, min-max scaling |

From the repository directory, after following [How to use Cobratate](../README.md#how-to-use-cobratate-on-your-computer):

```bash
python cobratate.py examples/intro/hello.cbt
python cobratate.py examples/dsa/bubble.cbt
python cobratate.py examples/ml/knn.cbt
```
