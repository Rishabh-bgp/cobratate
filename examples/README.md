# Examples

Programs are grouped so a reader can find a construct without reading the whole tree.

| Directory | Contents |
| --- | --- |
| `intro/` | Print, loops, functions, garages |
| `numbers/` | Primes, Euclid, Collatz, Fibonacci, binomial coefficients, bases |
| `dsa/` | Sort, search, stack, two-sum, breadth-first search |
| `ml/` | Linear regression, a perceptron, nearest neighbour, min-max scaling |

The catalogue, including the checked results, is [docs/programs.md](../docs/programs.md).

```
python cobratate.py examples/intro/hello.cbt
python cobratate.py examples/dsa/bubble.cbt
python cobratate.py examples/ml/knn.cbt
```
